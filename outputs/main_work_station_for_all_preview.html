Main Topic

Analyzing and Predicting Movie Success Across Film Industries

This group project studies movie success from two connected angles. First, the descriptive analysis investigates patterns in ratings, votes, genres, duration, box office revenue, budget, and movie personnel. Second, the machine learning analysis uses cleaned movie attributes to predict rating, revenue, audience engagement, release timing effects, and success categories.

The complete detailed work is kept in two work stations:

  • Descriptive Analysis Work Station
  • Machine Learning Work Station

Purpose Of The Study

The purpose of this project is to understand which movie characteristics are most related to audience evaluation and financial performance. Movie success is not measured by one variable only, so the project considers several indicators, including IMDb rating, number of votes, budget, worldwide gross revenue, opening revenue, release timing, and whether a movie can be classified as successful.

The study is designed to answer both explanatory and predictive questions:

  • Explanatory questions describe how movie characteristics differ across groups.
  • Predictive questions test whether machine learning models can use those characteristics to estimate future outcomes.

Problem Statement

The film industry is highly competitive, and producers, studios, distributors, and audiences all benefit from understanding what makes a movie successful. However, movie success can depend on many interacting factors, including genre, country of origin, duration, budget, release date, cast, directors, writers, and audience engagement.

The main problem is therefore:

Which movie characteristics best explain and predict movie success in terms of audience evaluation and financial performance?

Hypotheses Of The Study

The project is guided by the following hypotheses:

  1. Movies from different countries and film industries have different rating and revenue patterns.
  2. Some genres receive higher ratings and stronger audience engagement than others.
  3. Runtime influences audience ratings and votes, but the relationship may not be perfectly linear.
  4. Higher budgets are associated with higher box office revenue, although extreme blockbusters can create outliers.
  5. Well-known directors, writers, and stars may increase ratings, votes, or revenue.
  6. Release timing, such as month or season, influences box office performance and audience engagement.
  7. Machine learning models can predict rating, revenue, votes, and success categories better when movie features are cleaned and reduced to the most important predictors.

Methodology

The project follows a shared data science workflow:

  1. Load the movie dataset from the project Data folder.
  2. Clean important columns, including ratings, votes, duration, budget, gross revenue, release date, country, genre, stars, directors, and writers.
  3. Transform text-heavy columns into usable analytical or numeric features.
  4. Perform descriptive analysis using grouped summaries and visualizations.
  5. Build machine learning features for each prediction question.
  6. Split data into training and testing sets where prediction is required.
  7. Compare multiple models using appropriate metrics.
  8. Interpret results using plots, confusion matrices, residual plots, feature importance, and summary tables.

Descriptive Analysis

The descriptive analysis work station focuses on explaining patterns in the movie dataset before prediction. It uses summary statistics, grouped comparisons, and visualizations to describe how movie performance changes across genres, countries, duration, revenue, budget, and movie personnel.

Kay-Lee Dramat: Descriptive Q1-Q3

Q1: How Do Movie Ratings Vary Across Countries Or Film Industries?

Kay-Lee analyzed rating differences across countries or film industries. The goal was to identify whether some industries tend to have higher average ratings than others.

The descriptive results suggest that average rating can vary noticeably by country. Smaller or more selective film industries may appear near the top because fewer movies from those industries enter the dataset, while larger industries show more variation.

Q2: Which Genres Receive The Highest Ratings And Most Votes?

Kay-Lee compared genres using rating and vote information. This question connects audience evaluation with audience engagement.

The analysis shows that genres do not perform equally. Some genres tend to receive stronger average ratings, while others attract larger numbers of votes. This distinction matters because a highly rated genre is not always the same as a highly watched or highly voted genre.

Q3: How Does Movie Duration Influence Audience Ratings And Votes?

Kay-Lee examined the relationship between movie duration, ratings, and votes. Runtime was cleaned into numeric minutes so that it could be compared across movies.

The findings suggest that duration can influence audience response, but the pattern is not simply "longer is better." Very short or very long movies can behave differently, so duration should be interpreted alongside genre, audience size, and movie type.

Ghofrane Mahmoud: Descriptive Q4-Q6

Q4: How Do Box Office Revenues Differ Across Industries?

Ghofrane analyzed revenue differences across film industries using box office variables such as worldwide gross, US/Canada gross, and opening weekend revenue.

The analysis shows that revenue varies strongly across industries. Larger industries and markets tend to produce higher box office totals, while smaller industries may have fewer high-revenue films. Revenue distributions are highly skewed because a small number of blockbuster movies earn extremely large amounts.

Q5: Is There A Relationship Between Budget And Box Office Performance?

Ghofrane studied the relationship between budget and box office performance. Budget and revenue values were cleaned from text money formats into numeric values so they could be compared properly.

The results suggest a positive relationship between budget and box office revenue. However, this relationship is affected by outliers. Some movies with very large budgets earn very high revenue, while others do not recover their investment at the same level.

Q6: Do Movies With Well-Known Directors, Writers, Or Stars Receive Higher Ratings Or More Votes?

Ghofrane examined whether movie personnel are connected to stronger audience response. This included directors, writers, and stars.

The findings suggest that well-known movie personnel can be associated with higher visibility and audience engagement. However, star power alone does not guarantee high ratings or revenue, so personnel effects should be interpreted with genre, budget, and release context.

Aya and Meriam built regression models to predict movie rating using features such as genre, duration, budget, votes, release date, MPA rating, stars, and directors.

The final feature set was reduced to the top 8 most important predictors. The best model was selected using regression metrics such as MAE, RMSE, and R-squared. Q2: Can Box Office Revenue Be Predicted From Movie Characteristics?

Aya and Meriam built regression models to predict worldwide gross revenue. Because revenue is highly skewed, the target was log-transformed to make the model more stable.

The best model used cleaned numeric and categorical features, including popularity and budget-related predictors. The log revenue model performed better than predicting raw revenue directly because it reduced the influence of extreme blockbuster values.

Q3: Can We Predict Whether A Movie Will Receive A High Rating?

Aya and Meriam built a classification model for high-rated movies. The Q3 target was cleaned by removing ambiguous middle ratings, so the model compared clearly not high-rated movies against clearly high-rated movies.

The final version used balanced training data and four focused classifiers:

  • Logistic Regression
  • Random Forest
  • Gradient Boosting
  • Extra Trees

The best Q3 model was Random Forest. The cleaned and balanced setup created a stronger confusion matrix, especially for the predicted high-rated column, where correct high-rated predictions became clearly larger than false high-rated predictions.

Overall Findings And Discussion

The descriptive analysis shows that movie success is multidimensional. Ratings, votes, revenue, and personnel effects do not always move together. A movie can receive strong ratings without huge revenue, or high revenue without being one of the highest-rated films.

The machine learning analysis confirms that prediction improves when the data is cleaned carefully. Important improvements included:

  • parsing votes with K and M suffixes,
  • converting duration into minutes,
  • converting money columns into numeric values,
  • extracting release year, month, and movie age,
  • transforming skewed revenue or vote targets,
  • reducing very large feature sets to the top 8 predictors for Q1-Q3,
  • balancing and cleaning the classification target for Q3.

The strongest predictive results came from ensemble models such as Random Forest, Extra Trees, and Gradient Boosting. Linear models were useful as baselines, but tree-based models handled nonlinear relationships better.

Conclusions

This project found that movie success depends on a combination of creative, financial, timing, and audience-related factors. Genre, duration, budget, release timing, votes, revenue, and movie personnel all contribute useful information, but no single feature explains success by itself.

Descriptive analysis helped identify the main patterns in the data, while machine learning tested how well those patterns could predict outcomes. The final results show that cleaned and focused features can produce useful predictive models, especially for revenue and classification tasks.

The project also shows the importance of careful data preparation. Many movie fields begin as messy text, so parsing, transforming, and selecting features were essential steps before analysis and modeling.
